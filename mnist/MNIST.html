Que. What is MNIST Dataset?¶

Ans. The MNIST database of handwritten digits has a training set of 60,000 examples, and a test set of 10,000 examples.
It consist of digits written by high school students and employees of the United States Census Bureau, respectively.

Four files are available:

  1. training set images
  2. training set labels
  3. test set images
  4. test set labels

Loss Functions used in Categorical NN¶

1. Binary Cross-Entropy (BCE)

Used for binary classification problems where each output is classified into one of two classes (0 or 1).

Formula is,

$\large\text{BCE} = -\frac{1}{N} \sum_{i=1}^{N} \left[ y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \right]$

where,

  • $y_i$ is the true label (either 0 or 1),
  • $\hat{y}_i$ is the predicted probability for class 1.

2. Categorical Cross-Entropy (CCE)

Used for multi-class classification where the true labels are provided as one-hot encoded vectors.
e.g., [0, 1, 0], [1, 0, 0], [0, 0, 1]

The formula for Categorical Cross-Entropy is:

$\large\text{CCE} = -\frac{1}{N} \sum_{i=1}^{N} \sum_{c=1}^{C} y_{i,c} \log(\hat{y}_{i,c})$

where,

  • $y_{i,c}$ is the one-hot encoded true label for classes $c$,
  • $\hat{y}_{i,c}$ is the predicted probability for classes $c$,
  • $C$ is the number of classes.

3. Sparse Categorical Cross-Entropy (SCCE)

Similar to Categorical Cross-Entropy but used when the labels are provided as integer-encoded (not one-hot encoded).
e.g, [2], [3], [4].
This approach is more memory-efficient, especially when dealing with a large number of classes, as it avoids the need to convert labels into one-hot vectors.

The formula for Sparse Categorical Cross-Entropy is:

$\large\text{SCCE} = -\frac{1}{N} \sum_{i=1}^{N} \log(\hat{y}_{i, y_i})$

where,

  • $y_i$ is the true label (an integer representing the class),
  • $\hat{y}_{i, y_i}$ is the predicted probability for the true class.
